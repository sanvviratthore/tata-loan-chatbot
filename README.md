# 🏦 TATA LOAN CHATBOT

**TATA LOAN CHATBOT** is an AI-powered Conversational Assistant built for **Tata Capital** that helps users explore, compare, and consolidate their loans intelligently.  
It uses **multi-agent logic**, **automated credit profiling**, and **smart decisioning** to simulate a real loan journey — from inquiry to approval.

---

## 💡 FEATURES

⭐ **Identity Verification** – Verify users via PAN or registered mobile number  
⭐ **Auto Credit Scan** – Detect existing loans and analyze credit profiles  
⭐ **Smart Loan Consolidation** – Suggest single-EMI options with savings estimates  
⭐ **Loan Approval Simulation** – Auto-approve eligible users using underwriting logic  
⭐ **PDF Generation** – Create sanction letters and financial reports automatically  
⭐ **Edge Case Handling** – Manage low scores, multiple loans, and salary-slip uploads  
⭐ **Streamlit UI** – Clean chat-style interface for demonstrations  

---

## 🧭 MAIN FLOW

### 1️⃣ Initial Contact & Verification
> “I need a personal loan.”  
> → Chatbot verifies PAN or mobile number and authenticates user.

### 2️⃣ Credit Bureau Scan
> Detects all active loans, EMI amounts, and credit score.

### 3️⃣ Smart Consolidation Offer
> Suggests single EMI plan with savings breakdown.

### 4️⃣ Underwriting & Approval
> Approves loan if eligible and prepares sanction details.

### 5️⃣ Document Generation
> Generates downloadable **PDF sanction letter**.
